# Lab 01 — Installation et préparation du serveur

## Objectif

Installer et préparer un serveur Ubuntu afin de réaliser les différents travaux pratiques Linux.

## Environnement

- Ubuntu Server
- VirtualBox
- Serveur Linux
- Réseau NAT
- Terminal SSH

## Travail réalisé

- Installation d’Ubuntu Server.
- Création et configuration de la machine virtuelle.
- Configuration de base du serveur.
- Vérification du démarrage du système.
- Identification de la machine.
- Vérification de la connexion réseau.
- Préparation du serveur pour les labs suivants.

## Commandes de vérification

```bash
hostnamectl
cat /etc/os-release
ip addr
ip route
ping -c 4 8.8.8.8
```

## Résultat

Le serveur Ubuntu est installé et fonctionnel.

La machine est prête à être utilisée pour les labs suivants :

- Gestion des services SSH et Apache.
- Analyse de journaux et diagnostic.
- Gestion des utilisateurs, groupes et permissions.
- Diagnostic réseau Linux.
- Réseau privé et adresse IP statique.
- Pare-feu UFW et contrôle des accès.
- Mises à jour et audit système.
